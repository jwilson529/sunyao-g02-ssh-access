Sunyao G02 · A friendly guide

Your handheld.
Your access.

Prepare the SD card, run a tool from Ports, and connect your computer over Wi-Fi.

This enables administrator access. It does not update firmware.
Tested method: Sunyao G02 with EmuELEC 4.7, build 20260526095458. Other versions are not verified.

1Open the extracted folder

If you are still viewing the ZIP, right-click it and choose Extract All. Open the extracted folder in File Explorer.

You need a Windows PC, the handheld's game SD card, a card reader, and Wi-Fi. Shut the handheld down before removing the card.

2Prepare the card on your PC

Insert the card, then double-click Setup Windows.cmd in the extracted folder.

  1. Choose the card's drive letter using its label and size. Our label was G02ROMS.
  2. Type COPY to confirm. No formatting is performed.
  3. For a simple setup, press Enter at both key-passphrase prompts. A passphrase is optional; remember it if you choose one.
  4. Wait for READY — files copied and verified.

Your private key stays on this PC. Only the public key is copied to the card. Never share the private file named “sunyao-g02”.

3Find Ports on the handheld

Safely eject the SD card from Windows. Insert it into the powered-off handheld, then turn it on.

Ports is a game-system category, beside NES, SNES, PlayStation, etc. It is not inside Settings.

Game systems→Ports→01 - Check My Handheld

Run that first. Then launch 02 - Enable SSH Access.

A quick flash and return to the menu can be normal. The connection below will confirm whether it worked.

4Read the current IP address

Connect the handheld to Wi-Fi. Look in Network Settings for an address like 192.168.1.50. Keep it powered on and awake.

The IP can change after a reboot. Always read the current address rather than reusing an old one.

5Connect and check

On your PC, double-click Connect Windows.cmd. Type the handheld's current IP.

At the first connection, check the IP and type yes to trust the device. If you chose a key passphrase, enter it when asked.

At the command prompt, type id and press Enter. uid=0(root) means success. Type exit to disconnect.

Do not install a generic 4.8 update just because you now have access. Compatibility has not been established.

If it does not work

No Ports? Check the game-system categories, then the card's folder layout. Timeout? Check Wi-Fi, wake the handheld, and read its new IP. Permission denied? Read the result file.

Shut down, move the card to your PC, and open ports_scripts/G02-ENABLE-RESULT.txt. The diagnostic is G02-DIAGNOSTIC.txt in the same folder.

See the full troubleshooting guide online, or open docs/TROUBLESHOOTING.md in Notepad.

Want to undo access?

Run Ports → 03 - Remove SSH Access. Disconnect open sessions, then try connecting again. The package's key should no longer work. Other keys and the password are preserved.

Deleting the SD-card scripts alone does not revoke access. Never expose the handheld's SSH port through your router.
